# 中科酷原行业量子实验台 - 生物医药与材料领域 PRD

## 1. 产品决定

对外统一产品名称为“中科酷原行业量子实验台”。“生物医药”是产品内的一级领域，`CASCAQit` 是底层量子编程 SDK 和执行引擎名称，不作为工作台的对外产品名称。

本版本在统一行业量子实验台中建设生物医药领域，正式提供四个场景：

1. 小分子活性空间基态能量估计；
2. 靶点口袋与配体候选构象匹配优化；
3. 金属酶活性中心有效 Hamiltonian 与自旋耦合分析；
4. 小肽离散构象与折叠能景采样。

四个场景共用 CASCAQit 的本地编译、执行、结果和审计能力，但不强行使用同一种 Problem 类型或量子算法。电子结构和金属活性中心走 Pauli Hamiltonian + Digital VQE；分子对接走 QUBO + Hybrid QAOA；小肽能景走 QUBO + Digital QAOA。

产品展示中性原子量子计算的编程模型和问题映射，不声称量子优势，不提供药物、临床、诊断或治疗建议。当前执行全部来自本地模拟器，不是真实量子硬件结果。

当前量子计算尚不具备替代成熟经典计算流程的普遍条件，但产品不把“尚不能替代”解释为“无需探索”。工作台要让客户看到可立即开展的前沿价值：验证领域问题到量子模型的映射，比较 Digital、Hybrid 与 Pure Analog 技术路线，构建量子-经典协同和可审计实验流程，并沉淀未来更大规模、更高保真中性原子硬件可复用的数据、模型、基线和工程接口。页面必须同时呈现现实边界与发展前景，不把探索价值包装成已经实现的量子优势。

## 2. 目标用户

| 用户 | 主要问题 | 本产品提供的内容 |
|---|---|---|
| 药物研发管理人员 | 量子计算能进入药物研发的哪个环节 | 四个边界明确的实验流程和结果解释 |
| 计算化学研究人员 | Hamiltonian、Ansatz、测量和基线是否可信 | Pauli 项、测量分组、优化历史、经典对照和误差 |
| 计算生物学研究人员 | 组合优化如何表示结构约束 | 构象、接触、冲突、QUBO 系数和解码复核 |
| 量子算法工程师 | Digital、Analog、Hybrid 如何选择 | 模式分析、原子布局、项分配、线路、波形和 counts |
| 售前与解决方案人员 | 如何在有限时间内完成可解释演示 | 固定预设、推荐参数、稳定运行路径和明确限制 |

## 3. 产品目标

- 用户可以在一个工作台内完成四类生物医药实验的分析和执行。
- 每个结果可以追溯到输入数据、领域模型、Hamiltonian 或 QUBO、编译计划和执行记录。
- 页面分别展示量子候选、经典对照和参考数据，不用经典结果替换失败的量子候选。
- 四个标准场景在离线环境中可重复运行，不依赖现场网络和外部服务。
- 专业用户能够看到模型的适用范围、简化假设和未覆盖能力。
- 客户能够区分“当前不能替代经典计算”与“现在可以开展有意义的前沿探索”，并理解本阶段可沉淀的问题映射、协同流程和实验基线。

## 4. 不在本版本处理的内容

- 任意分子的一键电子结构计算；
- 连续空间的完整分子对接、结合自由能和分子动力学；
- 金属酶催化反应路径、活化能和真实酶活性预测；
- 全原子蛋白质折叠或真实蛋白结构预测；
- 从生产数据库读取化合物、患者、实验或临床数据；
- 真实中性原子硬件、云端编译和远程任务提交；
- 量子优势、全局最优或优于成熟经典软件的结论。

## 5. 演示主流程

```text
选择场景和预设
  -> 查看领域输入与数据来源
  -> 调整允许修改的领域参数
  -> 分析 Problem / Hamiltonian 与推荐模式
  -> 选择推荐配置或对照配置
  -> 执行本地量子实验
  -> 查看领域结果、经典对照和约束复核
  -> 查看线路 / 原子 / 波形 / counts
  -> 查看输入、编译和执行审计记录
```

首次进入场景时只运行分析，不自动触发耗时模拟。切换预设后清空旧执行结果；业务输入、算法、模式、shots、seed、层数或优化配置变化时，不得复用不同配置的 counts 和审计证据。

## 6. 公共页面

工作台沿用三栏结构：左侧场景导航，中间参数控制，右侧结果区域。结果区域包含以下视图：

| 视图 | 内容 |
|---|---|
| 领域结果 | 当前量子候选、参考结果、关键指标、可行性和未选原因 |
| 场景结构 | 分子、口袋、相互作用图、自旋网络或小肽构象 |
| Problem 映射 | Pauli Hamiltonian 或 QUBO、变量、项来源和模式分析 |
| 量子实验 | VQE/QAOA 参数、数字线路、原子布局、波形、测量组和 counts |
| 对照分析 | 精确对角化、经典枚举或参考结构与量子结果的差异 |
| 审计证据 | 固化实验数据、输入、analysis、compile、execution 和结果 hash |

页面始终显示以下运行边界：

- `LOCAL SIMULATION`；
- `NO HARDWARE EXECUTION`；
- `RESEARCH DEMONSTRATION`；
- 数据来源和许可证状态；
- 当前结果允许和不允许作出的解释。

## 7. 场景一：小分子活性空间基态能量估计

### 7.1 用户任务

用户选择一个已准备的小分子和几何预设，运行 Digital VQE，观察变分能量收敛、Pauli 测量成本以及与经典参考能量的差异。

### 7.2 标准预设

| 预设 | 用途 | 可调参数 |
|---|---|---|
| H2 键长扫描 | 验证能量曲线和解离趋势 | 键长、Ansatz 层数、shots、优化预算 |
| LiH 活性空间 | 展示多量子位 Hamiltonian | 键长、Ansatz 层数、优化器 |
| H2O 最小活性空间 | 展示更复杂的 Pauli 项和测量分组 | 几何预设、shots、噪声开关 |

每个预设使用仓库内固化的 Hamiltonian 实验数据（下文称 fixture）。fixture 必须记录分子几何、电荷、自旋、基组、冻结轨道、活性空间、映射方法、生成工具版本、来源和 checksum。

### 7.3 计算定义

- 输入：Pauli Hamiltonian、逻辑量子位顺序、参考 Hartree-Fock 位串和经典能量；
- 算法：Digital VQE；
- Ansatz：首期使用 CASCAQit hardware-efficient 或显式参数化线路；
- 目标：最小化 Hamiltonian 期望值；
- 测量：按 qubit-wise commuting 分组执行；
- 对照：精确对角化；可选显示 Hartree-Fock 能量。

### 7.4 页面结果

- 分子几何和活性空间说明；
- Pauli 项数量、测量组数量和逻辑量子位数量；
- VQE 收敛曲线、参数历史和停止原因；
- 最低评估能量、末端采样和精确基态能量；
- 绝对误差和相对误差；
- 噪声模型开启时，分别保存理想结果和带噪结果。

### 7.5 验收条件

- 三个预设均能完成分析，Hamiltonian hash 与 fixture manifest 一致；
- H2 至少一个标准键长在已验收预算下达到 1.6 mHa 以内的能量误差；
- LiH 和 H2O 必须报告误差，不设置未经校准的“化学精度”结论；
- 每个能量值可以追溯到具体参数点和测量结果；
- 页面不把末端最高频 bitstring 当成基态能量来源。

## 8. 场景二：靶点口袋与配体候选构象匹配优化

### 8.1 用户任务

用户选择一个公开共晶结构派生的离散对接数据集，调整匹配、应变和碰撞权重，使用 Hybrid QAOA 从候选相互作用中选择一个几何可行且构象一致的组合。

### 8.2 标准数据与预设

首个数据集优先采用 HIV-1 Protease/Indinavir 共晶结构 PDB `1HSG`。进入仓库前必须再次核对结构标识、来源和许可证，并保存原始文件 checksum 与派生脚本版本。

| 预设 | 变化 |
|---|---|
| 共晶参考 | 平衡氢键、疏水、芳香和应变评分 |
| 几何严格 | 提高碰撞、距离和角度偏差罚项 |
| 药效团覆盖 | 提高关键口袋特征覆盖权重和最低覆盖数 |

运行时只读取离线派生数据，不在浏览器或 API 请求中调用 PDB、RDKit、AutoDock 或其他网络服务。

### 8.3 决策变量与约束

一个业务变量表示一个候选配体特征与口袋特征的匹配是否被选择。

目标包括：

- 奖励几何兼容的氢键、疏水、芳香和静电匹配；
- 惩罚构象应变、距离偏差和角度偏差；
- 奖励关键口袋特征覆盖。

硬约束包括：

- 一个结果只能使用一个候选构象；
- 同一配体特征不能进入相互冲突的匹配；
- 同一口袋位置不能被不兼容特征重复占用；
- 空间碰撞的候选匹配不能同时选择；
- 必须满足最低关键特征覆盖数。

### 8.4 量子模式

- 推荐：Hybrid D-A-D QAOA；
- Analog core：碰撞、占位和两两互斥；
- Digital residual：构象唯一性、覆盖约束、目标权重和辅助变量；
- 对照：Digital QAOA；
- 纯 Analog 只有在完整 Hamiltonian 和业务图都能表达时才可用，首期不作为默认方式。

Hybrid 推荐必须同时满足：完整冲突贡献覆盖、无物理补边、无业务漏边、Digital residual 非空、项系数守恒和原子布局来源可审计。任一条件失败时降为 Digital，不为展示效果强行生成 Analog block。

### 8.5 页面结果

- 配体构象、口袋特征和候选相互作用图；
- 当前选择的匹配、构象、总评分和关键特征覆盖；
- 碰撞、占位、构象一致性和覆盖约束复核；
- Top-K 已观测可行候选；
- QUBO 贡献账本和 Analog/Digital 项分配；
- 原子布局、blockade interaction、D-A-D 时间线和控制波形；
- 与共晶参考相互作用的重合情况。

### 8.6 验收条件

- 三个预设均存在经典可行基线；
- 推荐配置在固定的三个 seed 下每次都观察到量子可行候选；
- 页面单独保存量子候选、经典最优和共晶参考；
- 所有冲突边都能追溯到具体空间或占位规则；
- 不输出结合自由能、Kd、Ki、IC50 或药效结论。

## 9. 场景三：金属酶活性中心有效 Hamiltonian

### 9.1 用户任务

用户调整有效交换耦合和局域场，运行 Digital VQE，比较不同参数下的基态能量、自旋关联和经典精确结果。

### 9.2 模型边界

本场景使用经典量子化学或文献模型派生的低能有效 Hamiltonian，不从蛋白质结构直接生成从头算电子 Hamiltonian。首期选择一个可说明来源的双金属活性中心模型，使用二到四个有效自旋自由度。

### 9.3 标准预设

| 预设 | 模型变化 |
|---|---|
| 反铁磁耦合 | 交换耦合偏向反平行自旋 |
| 配体场扰动 | 调整不同金属位点的局域场 |
| 耦合不平衡 | 两条或多条交换路径使用不同强度 |

### 9.4 计算定义

- 输入：带 `X/Y/Z` Pauli 项的有效 Hamiltonian；
- 算法：Digital VQE；
- 目标：最低能量；
- 观测量：单点磁化、两点自旋关联和声明的自旋扇区占据；
- 对照：精确对角化；
- Analog 对照：仅当模型退化为目标设备可完整表达的 `Z/ZZ` 形式时开放。

### 9.5 页面结果

- 金属中心、配位环境和有效自旋网络示意；
- `XX/YY/ZZ` 交换项和局域场；
- VQE 能量、精确能量和误差；
- 单点磁化与成对关联；
- 参数扫描下的能量和关联变化；
- 模型来源、适用范围和省略的化学效应。

### 9.6 验收条件

- 三个预设的 Hamiltonian、参数单位和参考值均有 manifest；
- VQE 和精确对角化使用同一个 Pauli Hamiltonian hash；
- 页面展示的关联函数来自执行结果，不由前端重算；
- 不输出催化势垒、反应速率、氧化还原电位或酶活性预测；
- 不把有效自旋位点描述成完整电子轨道或真实中性原子布局。

## 10. 场景四：小肽离散构象与折叠能景采样

### 10.1 用户任务

用户选择一个短肽序列和粗粒化能量预设，运行 Digital QAOA，在有限的自回避构象集合中观察低能构象、简并态和采样分布。

### 10.2 模型边界

首期处理 6～8 个残基的二维格点或等价的离散构象库。离线预处理枚举满足链连续和自回避条件的构象，并记录接触图、接触能和对称性归一化结果。量子问题负责在离散能景中选择低能候选，不模拟真实折叠动力学。

### 10.3 标准预设

| 预设 | 变化 |
|---|---|
| 疏水核心 | 疏水残基接触提供主要负能量 |
| 带电竞争 | 引入有利和不利的带电接触 |
| 接触受限 | 收紧允许接触数或排除部分构象 |

### 10.4 计算定义

- 输入：序列、离散构象、接触图和粗粒化能量；
- 变量：候选构象选择变量以及必要的辅助变量；
- 约束：恰好选择一个构象、禁用构象和可选的构象类别限制；
- 目标：最小化粗粒化接触能；
- 推荐：Digital QAOA；
- 对照：完整枚举的能景和最低能量集合。

该编码用于能景采样演示。它不把经典枚举伪装成量子求解，也不声称量子计算从氨基酸序列直接预测了结构。

### 10.5 页面结果

- 氨基酸序列、残基类型和能量模型；
- 候选构象缩略图和接触图；
- 能量直方图、简并度和当前候选；
- QAOA 参数历史和 counts；
- 量子已观测低能候选与完整经典能景的覆盖情况；
- 输入序列、构象库和能量矩阵 hash。

### 10.6 验收条件

- 三个预设均有不少于 8 个、最多 16 个去重构象；
- 所有构象通过链连续、自回避和接触图一致性检查；
- 经典基线列出全部最低能构象，不只返回一个；
- 固定 seed 的推荐配置至少观察到一个最低能或次低能可行构象；
- 页面明确使用粗粒化二维模型，不显示真实蛋白结构预测结论。

## 11. 数据与合规要求

每个数据集必须包含数据清单（manifest），至少记录：

- 数据集 ID 和版本；
- 原始来源、访问日期和许可证；
- 原始文件 checksum；
- 派生脚本版本和参数；
- 单位、坐标系和变量顺序；
- 经典参考方法、软件版本和结果；
- 已知限制和允许的演示说法。

仓库不得包含患者、临床试验受试者或未公开研发项目数据。公开结构和文献数据进入仓库前必须完成许可证核对。无法确认来源的数据只能作为明确标记的合成 fixture。

## 12. 非功能要求

### 12.1 离线与可重复

- 默认运行不访问网络；
- 同一输入、配置和 seed 产生稳定的分析、编译和结果标识；
- 所有预设随 Python 包安装；
- 报告写入用户数据目录，不写入只读安装目录。

### 12.2 性能

- 场景目录和单次分析目标为 2 秒内返回；
- 标准运行目标为 30 秒内完成；
- 超过 30 秒的研究配置必须在执行前显示预计成本；
- 页面运行期间保持响应，不阻塞健康检查和静态资源请求。

### 12.3 可用性

- 支持 `1440 x 900`、`1280 x 720` 和 `390 x 844`；
- 不出现页面级横向溢出、控件重叠和图表空白；
- 颜色不是区分选中、失败和告警的唯一方式；
- 专业缩写首次出现时提供中文解释或工具提示。

### 12.4 审计

每次执行保存数据集、领域输入、Hamiltonian/Problem、analysis、compile、算法配置、Backend、结果和报告 hash。页面不得根据展示需要重建量子线路、波形、测量结果或关联函数。

## 13. 发布条件

四个场景进入正式导航前必须同时满足：

- 输入验证、正向、边界和失败测试通过；
- 标准 fixture 的 hash 和经典参考测试通过；
- 推荐配置完成至少三个固定 seed 的独立运行；
- 量子候选与经典参考分开展示；
- 页面说明与当前实现一致；
- Python 测试、Ruff、TypeScript、React 测试和生产构建通过；
- 浏览器三种视口和图形非空检查通过；
- 所有数据来源、许可证和限制完成复核。

某个场景未通过发布条件时保留为内部研究入口，不以静态结果或经典结果替代量子执行。

## 14. 实施顺序

1. 建立生物医药数据 manifest、公共结果结构和场景目录；
2. 接通小分子 Pauli Hamiltonian + VQE，验证 Chemistry Adapter 边界；
3. 实现分子对接 QUBO 和 Hybrid 业务门禁，完成旗舰页面；
4. 复用 Pauli 执行链实现有效自旋模型；
5. 实现小肽离散构象能景和经典枚举对照；
6. 完成四场景联调、浏览器验收、离线打包和客户讲解文档。

## 15. V2 高级实验模式

### 15.1 版本定位

本节定义 V2 迭代需求，当前状态为 `COMPLETED`。第八至第十一阶段已经完成实验规划、四个高级场景、持久批量任务、高级页面和发布验收。现有四场景作为“标准实验模式”继续保留，用于快速讲解、回归验证和低配置设备；V2 在相同场景下增加“高级实验模式”，用于面向计算化学、计算生物学和量子算法专业人员的深度演示。

高级模式的目标不是单纯扩大逻辑量子位，而是同时提高四类复杂度：

- 领域模型包含更多候选、相互作用、约束或参数点；
- 量子实验支持配置对照、重复 seed、噪声敏感性和资源成本分析；
- 结果包含分布、稳定性、误差和失败原因，不只展示一个最优值；
- 大规模领域输入通过可审计的确定性裁剪形成适合本地模拟的量子子问题。

标准与高级模式共用数据来源、Problem/Hamiltonian、CASCAQit 执行和审计链。高级模式不得使用预计算量子结果冒充实时执行，也不得因量子子问题缩小而隐去被裁剪的业务变量。

四个场景的复杂度基线如下。表中的“完整规模”描述领域输入，“活动规模”描述送入 CASCAQit 的量子子问题；两者必须在分析页和报告中同时出现。

| 场景 | 高级完整规模 | 高级活动规模 | 批量实验 | 主要输出 |
|---|---|---|---|---|
| 小分子电子结构 | 同一分子 5～9 个几何点 | 高级实时 4～6 量子位，研究档 6～8 量子位 | 几何点 × 2～3 组 VQE 配置 × 1～5 个 seed | 势能趋势、逐点误差、收敛稳定性和测量成本 |
| 候选构象匹配 | 2～4 个构象、8～12 个口袋特征、20～40 个候选匹配 | 10～16 个业务变量及必要辅助变量 | 权重方案 × Digital/Hybrid 配置 × 1～5 个 seed | Top-K 可行候选、覆盖率、裁剪证据和模式差异 |
| 金属活性中心 | 3～4 个自旋位点、3～6 条交换路径 | 3～4 量子位有效 Hamiltonian | 5～9 个参数点 × VQE 配置 × 1～5 个 seed | 能量、经典能隙、磁化、关联矩阵和参数趋势 |
| 小肽离散能景 | 8～10 个残基、32～64 个离线去重构象 | 10～16 个活动构象 | 序列/能量扰动 × QAOA 配置 × 1～5 个 seed | 能景盆地、低能覆盖、结构多样性和采样分布 |

### 15.2 公共高级能力

| 能力 | 产品要求 |
|---|---|
| 实验级别 | 场景页提供“标准 / 高级”分段选择；切换级别后重新分析并清空不兼容结果 |
| 复杂度概览 | 执行前展示领域规模、逻辑量子位、Pauli/QUBO 项、测量组、线路深度估算、shots 和目标评估预算 |
| 配置对照 | 同一输入可以比较最多 3 组算法配置；每组结果保留独立 hash，不合并 counts |
| 重复实验 | 支持 1～5 个固定或用户指定 seed，报告成功率、中位数、四分位距和最佳/最差结果 |
| 参数扫描 | 支持场景声明的有限参数网格；扫描点必须有独立输入和结果标识 |
| 子问题裁剪 | 记录完整领域问题、裁剪规则、保留/排除变量、覆盖率和量子子问题 hash |
| 成本门禁 | 超过本地预算时禁止直接同步运行，允许降低规模、降低预算或转为研究任务 |
| 结果解释 | 量子候选、经典基线、公开参考和预计算领域数据始终分栏展示 |

高级模式只允许目录中登记的规模档位，不接受浏览器提交任意 Hamiltonian、可执行脚本或无限参数网格。

### 15.3 场景一高级需求：多点势能面与 VQE 对照

高级电子结构实验增加以下能力：

- 对同一分子执行 5～9 个几何点的键长或键角扫描，形成完整的势能趋势，而不是只展示单点能量；
- “高级实时”档使用 4～6 个逻辑量子位，“研究”档可使用 6～8 个逻辑量子位；每个档位的 Pauli 项和 QWC 测量组上限写入 manifest；
- 比较 2～3 组 Ansatz 层数、优化预算或噪声配置，并显示参数量、目标评估次数和测量成本；
- 同时展示 Hartree-Fock、精确对角化、理想 VQE 和带噪 VQE，计算每个几何点的绝对误差；
- 对扫描曲线报告最低点位置、趋势一致性和未收敛点，不用插值掩盖失败执行。

验收要求：

- 所有扫描点来自同一版本化 fixture 集合，几何、Hamiltonian 和参考结果逐点可追溯；
- 至少一个 4～6 量子位高级预设在发布机上完成 3 个固定 seed；
- 参数量、测量组和目标评估次数与实际执行记录一致；
- 未达到误差目标时显示真实误差和停止原因，不回退到精确能量作为量子结果；
- 激发态能隙在本阶段只允许作为经典精确参考；CASCAQit 未提供经验证的 VQD/子空间算法前，不声称由量子执行得到激发态。

### 15.4 场景二高级需求：多构象、多目标离散匹配

高级构象匹配实验使用更丰富的离散业务图：

- 原始领域问题包含 2～4 个配体构象、8～12 个口袋特征和 20～40 个候选匹配；
- 评分同时包含几何匹配、关键药效团覆盖、构象应变、碰撞、占位和构象一致性；
- 确定性预处理保留 10～16 个业务变量及必要辅助变量进入实时量子子问题；被排除候选及原因必须可查看；
- 支持 3 组权重方案和权重敏感性比较，观察候选排名、可行率和关键特征覆盖变化；
- 返回 Top-K 已观测可行候选、经典最优候选和共晶派生参考，分别计算重合度与评分差异；
- Hybrid 模式必须继续通过冲突图完整性、无补边、无漏项和 Digital residual 非空门禁。

验收要求：

- 完整领域图与裁剪后 QUBO 均有变量账本和稳定 hash；
- 裁剪规则在相同输入下确定性重复，且所有强制关键特征至少保留一个候选；
- 三个固定 seed 中至少观察到一个可行候选；可行率低时不得以经典最优替换；
- Digital 与 Hybrid 对照使用相同的逻辑 QUBO 和评分函数；
- 页面继续禁止结合自由能、亲和力、药效和临床结论。

第十阶段按以下固定规模实现首个高级预设，后续扩大规模时仍受 `advanced_live` 配置上限约束：

| 项目 | 完整领域问题 | 量子活动子问题 | 页面与报告必须显示 |
|---|---:|---:|---|
| 构象 | 3 个 | 3 个构象选择变量 | 每个构象至少保留 2 个候选匹配 |
| 候选匹配 | 24 个 | 9 个匹配变量 | 15 个排除项及逐项原因 |
| 冲突关系 | 12 条 | 4 条活动冲突 | 完整冲突数与活动冲突数 |
| QUBO | 不直接构造 28 变量实时问题 | 13 个变量、70 个非零项 | 9 个匹配变量、3 个构象变量、1 个覆盖辅助变量 |

三个高级权重预设为 `multi_pose_balanced`、`multi_pose_geometry` 和 `multi_pose_coverage`。它们使用同一份完整业务图和确定性选择规则，便于比较权重变化，不允许为某个预设手工挑选更有利的活动变量。

### 15.5 场景三高级需求：多中心有效自旋网络

高级活性中心实验从双位点模型扩展到 3～4 个有效自旋位点：

- 模型包含 3～6 条交换路径、各向异性的 `XX/YY/ZZ` 系数和可选局域场；
- 可选横向或交叉 Pauli 项只有在 CASCAQit Hamiltonian、Ansatz 和测量链通过能力测试后开放；
- 支持 5～9 个有限参数点，扫描交换耦合、局域场或配体场扰动；
- 展示基态能量、精确能隙、单点磁化、两点关联矩阵和声明的自旋扇区权重；
- 对参数扫描标记关联符号变化、近简并区间和 VQE 未收敛点。

验收要求：

- 每个参数点由模板 Hamiltonian 和参数实例化得到，模板 hash 与实例 hash 分开保存；
- 3 位点和 4 位点至少各有一个经过经典精确复核的预设；
- 关联矩阵满足对称性、取值范围和同一 Hamiltonian hash 约束；
- 精确激发态能隙只能标记为经典参考，除非后续接入并验证量子激发态算法；
- 不从模型参数推导催化势垒、反应速率、氧化还原电位或酶活性。

### 15.6 场景四高级需求：更大构象库与能景盆地

高级小肽实验提高领域规模，但继续保持粗粒化边界：

- 支持 8～10 个残基的版本化序列和 32～64 个离线去重构象；
- 接触能包含残基类型相关项、有利/不利带电接触和可选构象类别约束；
- 后端根据能量窗、结构多样性和约束覆盖确定性选择 10～16 个构象形成实时量子子问题；
- 识别能景盆地、局部极小值、简并基态和不同盆地之间的能量差；
- 支持最多 3 个单残基替换或能量矩阵扰动预设，比较低能构象覆盖和盆地迁移；
- 研究档可评估转向/接触（turn/contact）编码，但在 CASCAQit 提供并验证约束保持混合算子（mixer）前，正式演示继续使用可审计的候选选择 QUBO。

验收要求：

- 完整构象库全部通过链连续、自回避、对称性去重和接触图一致性检查；
- 量子活动窗口至少覆盖经典最低能集合中的一个代表，并保留每个主要能景盆地的代表；
- 页面同时展示完整经典能景和量子活动窗口，不能把 10～16 个候选描述成全部构象；
- 三个固定 seed 至少观察到最低能、次低能或同一最低能盆地中的可行构象，并如实报告覆盖率；
- 不展示真实三维蛋白结构、折叠动力学或生物功能预测结论。

第十阶段按以下固定规模实现八残基高级预设：

- 完整库含 48 个二维自回避构象，按接触图汉明距离确定性分为 8 个盆地；大小至少为 4 的 6 个盆地定义为主要盆地；
- 活动窗口固定为 12 个构象。选择器保留全部完整经典基态、每个主要盆地的最低能代表，再按 1.5 无量纲能量窗和接触图多样性补满；
- 实时 QUBO 含 12 个 one-hot 变量和 78 个非零项；完整能景 hash、选择规则 hash 与活动 QUBO hash 分开保存；
- 三个高级预设为 `octapeptide_hydrophobic`、`octapeptide_charge_shift` 和 `octapeptide_mutation`，分别用于疏水核心、电荷位移和单序列变体对照；
- 页面默认只绘制按能量排序的前 24 个完整构象，仍显示完整总数 48、活动数 12、覆盖率 25% 和 36 个排除项，避免大量结构挤压结果视图。

### 15.7 CASCAQit 能力依赖

以下判断以当前锁定的 CASCAQit `1.0.5a0` 及本仓库已经验证的调用面为准：

| 能力 | 当前状态 | V2 处理方式 |
|---|---|---|
| 通用 Pauli Hamiltonian、Digital VQE、QWC 测量、本地模拟 | 已支持 | 复用并增加批量编排、规模门禁和对照聚合 |
| QUBO、Digital QAOA、ProblemCompiler、Hybrid D-A-D | 已支持 | 复用，保持系数守恒和几何门禁 |
| 分子积分、活性空间选择和费米子到量子位映射 | SDK 不负责 | 由离线 Chemistry Adapter 生成版本化 fixture |
| 连续空间对接、构象生成和口袋识别 | SDK 不支持 | 由离线经典工具生成候选，运行时只解离散子问题 |
| 参数扫描、重复 seed 和跨配置统计 | 应用层已支持 | 使用持久化本地任务、独立运行单元和实验矩阵 |
| VQD、子空间展开等量子激发态算法 | 尚未验证 | V2 不作为量子结果；后续需扩展 SDK 算法和结果契约 |
| 约束保持混合算子、动态混合算子 | 尚未验证 | 正式路径继续使用罚函数 QUBO；研究入口受能力开关控制 |
| 长任务进度和协作式取消 | 应用层支持运行单元进度和排队取消；SDK 回调不足 | 运行中取消保持不可用，需 SDK 增加检查点 |

任何标记为“尚未验证”的能力必须通过独立 SDK 能力测试、应用集成测试和发布校准后才能在正式页面开放。

### 15.8 高级模式性能与降级规则

- 分析接口仍以 2 秒内返回为目标，必须在执行前给出成本估算和预算判定；
- 高级模式的单个实时运行单元目标为 60 秒内完成；包含多个扫描点、配置或 seed 的计划，以及研究配置，必须使用长任务协议；
- 默认并发只允许一个重计算任务，health、静态资源和结果查询不得被阻塞；
- 超出量子位、Pauli 项、测量组、QUBO 变量、shots 或目标评估预算时返回结构化诊断，不静默截断；
- 用户可以显式选择系统建议的较小规模或较低预算；降级后的配置生成新的 analysis hash；
- 本地模拟规模上限由发布机校准确定，不把模拟器可运行规模等同于真实中性原子硬件能力。

### 15.9 V2 发布条件

高级模式进入正式导航前必须同时满足：

- 四个场景各有至少一个高级预设和一个标准预设完成回归；
- 高级预设的数据、裁剪、量子子问题、经典参考和结果聚合均可审计；
- 每个推荐配置完成至少三个固定 seed，报告成功率、中位数与四分位距；
- 标准模式的性能、结果和既有 API 不发生回归；
- 超预算、部分扫描失败、任务取消和损坏 fixture 均有自动化测试；
- 三种视口能够完整显示复杂度概览、对照矩阵和长任务状态；
- 文档、页面和报告明确区分“完整领域问题”“量子活动子问题”和“经典参考”；
- 所有 CASCAQit 新能力都已通过版本门禁，不依赖未发布的本地补丁。

## 16. V3 生物分子动态、RNA 与材料扩展

### 16.1 产品决定

本节定义客户反馈形成的 V3 需求，当前状态为 `FINAL ACCEPTANCE / BROWSER PENDING`。RNA、蛋白构象路径、材料构型优化和材料 Pure Analog AHS 四类新增场景均已实现；八场景 84 次固定 seed 证据、全量自动化、wheel 和当前 Windows 离线包构建侧验收已完成。显式发布条件中的 Chromium 三视口截图仍受宿主 macOS Mach 服务策略阻断，因此 V3 尚不标记为 `COMPLETED`。产品严格区分两类任务：Digital/Hybrid 负责离散优化，纯 Analog 负责目标 Hamiltonian 能由 Rydberg 相互作用完整表达的时间演化。

当前生物医药与材料案例已由四个生物医药场景扩展为八个：

- 生物医药保留现有四个场景，新增“RNA 二级结构集合与折叠路径”和“蛋白构象转变路径与动力学网络”；
- 材料科学作为独立一级领域，包含“催化表面缺陷与吸附协同构型优化”和“材料缺陷晶格中的 Rydberg 动力学与量子淬火”；
- 金融、生物医药和材料科学共用工作台外壳、任务服务和审计能力，但材料数据与类型不放入生物医药目录。

RNA 和材料构型优化已经成为正式演示场景。蛋白构象转变保留研究入口定位，因为 CASCAQit 能够求解离散路径优化，但不能直接完成全原子长时间分子动力学。材料 Rydberg 动力学已接入 CASCAQit `1.0.5a` 的 `AHSProgram`、目标校验、显式 `SimulationState` 和 `AnalogStateVectorKernel`：每个请求时刻从同一声明初态执行截断后的真实 AHS 程序，形成四位点时分辨观测量；不插值、不复用终态，也不使用经典参考回填 Analog 字段。

### 16.3 场景五：RNA 二级结构集合与折叠路径

#### 16.3.1 用户任务

用户选择一段经过校验的短 RNA 序列，查看候选碱基配对和结构约束，运行 QAOA 或满足几何门禁的 Hybrid 实验，获得多个已观测的低能可行二级结构，并与经典动态规划或枚举结果比较。

#### 16.3.2 模型和数据边界

- 输入使用版本化短序列、允许配对规则、最小环长、候选茎、能量参数和参考结构；
- 标准模式默认只支持 Watson-Crick 配对和声明的 G-U 摆动配对；假结作为独立预设，不在默认模型中隐式加入；
- 完整候选集合可以大于实时量子子问题，但必须记录保留、排除和强制候选；
- 运行时不从头预测 RNA 三维坐标，不执行显式溶剂分子动力学；
- QAOA counts 只表示本次量子采样分布，不能直接解释为温度相关的热力学构象概率。

#### 16.3.3 QUBO 定义

每个候选碱基对或候选茎对应一个二进制变量。目标函数包含配对收益、堆叠收益、未配对代价和可选结构先验；约束至少包含单核苷酸配对次数、最小环长、候选兼容性和模式声明的假结规则。每一项必须回溯到序列位置、能量参数版本和贡献账本。

Digital QAOA 是默认模式。只有冲突图完整、没有补造物理边、Digital residual 非空且原子布局通过现有 Hybrid 门禁时，页面才推荐 Hybrid D-A-D。

#### 16.3.4 页面结果与验收

- 展示序列、弧线配对图、候选茎、约束冲突和 Top-K 已观测可行结构；
- 分别展示量子候选、经典最优结构、公开参考结构和离线能量参数；
- 报告可行率、低能覆盖、碱基配对重合度、结构多样性和每个候选的 QUBO 分解；
- 至少提供三个固定 seed，任一 seed 未观察到可行结构时保持失败结果，不以经典结构替换；
- 若展示经典分区函数或配对概率，必须标记为经典计算结果，不得从 QAOA 频率推导。

#### 16.3.5 第十三阶段交付状态

`BIO-V3-RNA-01` 首版已实现并登记为 `available`。当前开放三个版本化预设：`hairpin_reference`、`stem_competition` 和 `limited_pseudoknot`；用户可以在 3–6 nt 范围内调整最小环长，但不能提交自由序列或任意能量脚本。执行链固定为 Digital QAOA、`p=1` 和本地状态向量模拟，Hybrid/Analog 均返回不支持诊断。

结果分别保存本次量子观测 Top-K、有限候选空间经典精确枚举、无假结动态规划基线和数据集参考结构。教学配对分数是无量纲模型值，不是自由能；QAOA counts 是有限 shots 观测频次，不是 Boltzmann 分布或碱基配对概率。三个固定 seed `7/23/41` 的校准不得用经典结果回填未观测量子候选。

### 16.4 场景六：蛋白构象转变路径与动力学网络

#### 16.4.1 用户任务

用户选择一个由公开实验结构、公开轨迹或离线经典分子动力学生成的构象状态网络，指定起始态和目标态，使用量子组合优化搜索满足连通性约束的低代价转变路径，并查看候选路径对不同能垒或边权参数的敏感性。

#### 16.4.2 模型和科学边界

- 节点表示已经定义的亚稳构象，边表示离线数据中允许的直接转变；
- 边权可以来自自由能差、估计能垒或经典转移统计，但来源和单位必须写入 manifest；
- 首期只优化有限状态网络中的路径、路径长度或瓶颈代价，不从氨基酸序列生成蛋白构象；
- 页面使用“转变路径”“状态顺序”和“路径代价”，没有经典动力学依据时不得显示真实时间、驻留时间、速率常数或动力学轨迹；
- 不声称完成全原子蛋白折叠、真实蛋白结构预测或量子分子动力学。

#### 16.4.3 计算和验收

路径变量可以表示节点是否进入路径、边是否被选择或离散时间片上的状态。QUBO 必须完整表达起点、终点、流守恒、路径连续、禁止回路和最大路径长度；使用辅助变量时单独记录其来源。

- 展示完整状态网络、量子活动子图、起点、终点、候选路径和排除节点；
- 将量子观测路径与 Dijkstra、动态规划或小规模枚举基线分开显示；
- 对至少两个边权预设和三个固定 seed 报告路径可行率、代价、重合度和失败原因；
- 活动子图裁剪不得删除起点、终点或所有可行通路；
- 实时量子演化、时间关联函数或跃迁速率在 CASCAQit 完成独立能力验证前不进入正式结果字段。

#### 16.4.4 第十四阶段交付状态

`BIO-V3-PROTEIN-DYN-01` 首版已实现并登记为 `available`。场景使用 7 状态、15 条有向允许转移的版本化教学网络，提供 `open_to_closed`、`barrier_shift` 和 `alternate_basin` 三个边权预设。公开实验结构只作为开放态/闭合态端点标签；中间态与边权是项目编写的粗粒化教学数据，不冒充实验动力学或经典 MD 轨迹。

连接优先选择器先锁定起点、终点和完整低代价通路，再保留一个高覆盖竞争中间态；活动子图固定为 4 个状态并保留 2–3 条有界通路。标准 `maximum_steps=3..4` 使用 9–12 个时间片状态变量。QUBO 的起点后继、终点固定、单时间片单态、相邻允许转移、非终点状态重复禁止和有限时间片长度分别记录为约束组，贡献账本守恒。

默认配置为 Digital QAOA、`p=1`、256 shots、4 次 COBYLA 目标评估和 seed `7`。三个预设 × seeds `7/23/41` 共九次校准有六次观测到可行路径，可行 shot 比例为 0–2.734375%；三次未观测结果保留 `quantum_not_observed`、失败原因和空 `quantumCandidate`，没有使用有界 Dijkstra 结果回填。页面和报告只把 `pathCost` 解释为 `dimensionless_model_cost`，不输出真实时间、速率、驻留时间或蛋白分子动力学轨迹。

### 16.5 材料场景：催化表面缺陷与吸附协同构型优化

#### 16.5.1 用户任务

用户选择一个版本化催化表面模型和吸附物预设，同时优化空位或掺杂位置、吸附位点、吸附取向和覆盖度，在给定离线能量模型下寻找低能可行构型。

#### 16.5.2 模型和数据边界

- 输入包含晶格、周期边界、表面对称性、候选缺陷、候选吸附位点、互斥关系和离线能量参数；
- 能量项可以包含缺陷形成能、吸附能、近邻相互作用和覆盖度惩罚，每项必须记录来源、单位和计算方法；
- 离线参数可以来自公开材料数据库、公开论文或经过校验的 DFT 计算；运行时不执行 DFT，也不从量子采样反推电子密度；
- 首期结果只说明给定离散模型下的构型目标值，不推导催化活性、反应速率、选择性、稳定性或可合成性。

#### 16.5.3 QUBO 与 Hybrid 条件

缺陷、掺杂、吸附位点和取向分别使用业务变量。约束至少覆盖同一晶格位点占用、同一分子取向互斥、化学计量、覆盖度、邻位排斥和预设允许的缺陷-吸附组合。对称等价构型由离线材料适配器去重，不能在量子运行后删除不利结果。

Digital QAOA 负责通用 QUBO。Hybrid 只接收经过验证的局域冲突组；晶格距离不能自动等同于 Rydberg 几何，任何物理边补充、业务边遗漏或系数不守恒都必须拒绝 Hybrid 推荐。

#### 16.5.4 页面结果与验收

- 材料科学作为独立一级领域，提供晶格/表面视图、缺陷与吸附图例、周期单元和构型对照；
- 展示 Top-K 已观测可行构型、完整业务变量、量子活动变量、排除账本和目标分解；
- 分别显示量子候选、经典枚举或整数规划基线、公开或 DFT 参考数据；
- 至少一个预设同时包含缺陷变量和吸附变量，证明场景不是单一最大独立集示例；
- Digital 与 Hybrid 使用相同逻辑 QUBO，三个固定 seed 至少观察到一个可行构型；失败时不使用经典最优构型替代。

#### 16.5.5 第十三阶段交付状态

`MAT-V1-ADSORB-01` 首版已实现并登记为 `available`。三个版本化预设分别覆盖 CeO2(111) 氧空位 / CO、TiO2(110) 氧空位 / H2O 和 MoS2 硫空位 / H；每个预设使用同一组 3 个缺陷变量与 8 个吸附构型变量。目标函数同时包含缺陷形成能、吸附能、缺陷-吸附协同和周期近邻相互作用，硬约束覆盖缺陷计量、覆盖度、同位点/取向互斥和禁配组合。

Digital 与 Hybrid 共用 11 变量、47 个非零项的逻辑 QUBO。Hybrid 只映射四组经过验证的局域互斥边；当前编译证据为 15 个 Analog 项和 32 个 Digital residual 项，系数贡献账本守恒且没有补边或漏边。材料晶格、对称归一后的有效变量和 CASCAQit 编译坐标分别标识。

默认演示配置为 Hybrid QAOA、`p=1`、128 shots、两组固定审查参数。三个预设 × seeds `7/23/41` 共九次校准均观测到可行构型，可行 shot 比例为 2.34%–10.16%；证据保存在 `docs/process/evidence/materials_defect_adsorption_calibration.json`。量子未观测到可行构型的通用分支仍返回 `quantum_not_observed`，不复制经典枚举最优或离线参考。所有系数是无量纲离线教学模型，运行时不执行 DFT。

### 16.6 材料场景：缺陷晶格 Rydberg 动力学与量子淬火

#### 16.6.1 用户任务与 Analog 边界

用户选择理想晶格、单空位或多缺陷/局域杂质预设，检查有效晶格模型到 Rydberg 原子阵列和脉冲的映射，制备声明的初态并执行量子淬火，观察激发如何随时间传播、受阻或局域化。该场景从 `AHSProgram` 进入原生 Analog 执行链：不生成数字门、不构造 QUBO、不包含 Digital residual，也不使用 Hybrid D-A-D。

场景模拟的是材料问题的有效多体 Hamiltonian，不是材料晶体的全电子或全原子实时演化。材料晶格坐标、有效模型位点和 Rydberg 编译坐标是三个不同对象，页面和审计载荷必须分别标识，不能把 Rydberg 原子阵列描述为真实材料原子排布。

#### 16.6.2 Hamiltonian、预设与输入

首期目标 Hamiltonian 为：

\[
H(t)=\sum_i \frac{\Omega_i(t)}{2}X_i-\sum_i\Delta_i(t)n_i+\sum_{i<j}V_{ij}n_i n_j
\]

其中 \(\Omega_i(t)\) 是全局或局域 Rabi 驱动，\(\Delta_i(t)\) 是失谐，\(V_{ij}\) 来自经过目标校验的 Rydberg 相互作用。进入纯 Analog 路线前，完整目标项必须都能由 Analog 能力表达；不得隐藏数字项、遗漏业务相互作用或为得到预期图形补造相互作用。

首期至少提供三个版本化预设：

- 理想晶格：无缺陷的基准传播，用于检查对称性、Rabi 振荡和关联增长；
- 单空位：移除一个有效位点或将其标记为不可激发，比较缺陷两侧的传播和局域占据；
- 多缺陷/局域杂质：使用有来源的局域失谐或位点模式，展示散射、阻塞增强或局域化趋势。

每次实验输入必须包含材料有效晶格、Rydberg 寄存器坐标、初态制备方案、Rabi 波形、Detuning 波形、相位、演化时长、采样时刻、shots、seed、目标快照和单位。首版只开放固定 fixture 与经过校验的参数范围，不接受浏览器提交任意脚本。若 CASCAQit 发布版本只支持全基态初态或终态采样，页面必须把对应配置标为不支持，不能在应用层伪造可编程初态或时间序列。

#### 16.6.3 结果、经典对照与验收

结果页以时间轴同步展示脉冲、逐位点 Rydberg 激发概率、平均激发或磁化、两点关联矩阵、缺陷两侧传播前沿和局域化指标。每个时间点都必须关联 program hash、target snapshot hash、initial-state hash、pulse-schedule hash、solver evidence 和实际采样时刻；缺失时间点保留失败状态，不做平滑补值。

小规模结果与独立经典精确时间演化或可解析极限比较，分别报告逐位点概率误差、关联函数误差、范数守恒和时间步收敛。经典结果只出现在 `classicReference`，不得回填 Analog 结果字段。全部执行继续标记 `LOCAL SIMULATION` 和 `NO HARDWARE EXECUTION`，不得声称真实硬件运行或量子优势。

场景转为可运行至少满足：

- 发布 wheel 中的 AHS 构造、目标校验、离散化和本地执行契约测试通过，运行时版本满足项目依赖范围且模块来源可审计；
- 纯 Analog 证据表明 Digital gate count 和 Digital residual 均为零，目标 Hamiltonian 没有缺项或补项；
- 原子坐标、最小间距、Rabi/Detuning 振幅、斜率、持续时间和采样时刻全部通过目标约束；
- 初态制备与时间序列由 SDK 的受测接口产生，不用重复终态结果冒充单次连续轨迹；
- 三个预设、三个固定 seed 均返回可追溯结果；任一运行失败时不使用经典曲线替代。

#### 16.6.4 第十五阶段交付状态

`MAT-V1-AHS-01` 已实现并登记为 `available`。三个版本化预设各自选择 4 个活动位点，分别覆盖理想方形窗口、单空位传播窗口和带局域失谐的多缺陷/杂质窗口。材料晶格、活动窗口和 Rydberg 寄存器保持三个独立坐标身份；初态、脉冲、目标快照、采样时刻、程序和结果分别哈希。

高层 `LocalAhsSimulator.run()` 仍是全基态终态接口，因此本场景没有把它的多次终态拼接成轨迹。应用从同一个 fixture 声明初态出发，对每个非零时刻构造覆盖 `[0,t]` 的完整 AHS 前缀程序，经目标校验后交给公开 `AnalogStateVectorKernel` 执行；零时刻仅返回声明初态。独立 SciPy DOP853 参考只进入 `classicReference`。Pure Analog 账本要求 Digital gate、Digital residual 和 Hybrid block 均为零，声明 Hamiltonian 项与映射项一一对应。

发布校准覆盖三个预设和 seeds `7/23/41`，共 9 次运行；每次使用 9 个采样时刻、每时刻 128 shots。9/9 通过，最大逐位点占据绝对误差为 `5.12e-6`，最大二点关联绝对误差为 `9.82e-6`，最小终态保真度为 `0.9999999998`。该结果只证明四位点本地有效模型的实现一致性，不构成真实材料动力学或量子优势声明。

### 16.8 CASCAQit 增强需求

V3 的 RNA 和材料构型优化不要求修改 CASCAQit 核心，可以复用现有 QUBO、QAOA、ProblemCompiler、Hybrid D-A-D、LocalBackend 和持久任务。纯 Analog 材料动力学可以复用源码中已有 AHS 基础对象，但正式接入仍需要补齐下表能力：

| 缺口 | 所属层 | V3 未完成时的处理 |
|---|---|---|
| RNA 序列到候选配对、能量和约束 | 应用层 RNA Adapter | 首版已完成版本化短序列、候选配对、教学评分和约束；仍不接受自由序列或浏览器上传任意能量脚本 |
| 蛋白轨迹到构象状态网络 | 应用层 Conformation Network Adapter | 只接受版本化 fixture，不把路径称为真实动力学 |
| 材料晶格、周期边界、对称性和能量导入 | 应用层 Materials Adapter | 只接受已校验的离线材料数据 |
| Gibbs 态或有限温度量子采样 | CASCAQit 算法层 | RNA counts 不解释为热力学概率 |
| AHS 发布包契约、版本来源和应用执行器 | CASCAQit 发布工程 + 应用层 Analog Executor | 已在分析与执行时校验 `>=1.0.5a0,<1.0.6`、模块来源、公开类型和目标快照；wheel 内容在第十五阶段验收 |
| 时分辨 AHS 轨迹和采样时刻 | CASCAQit 模拟器与结果层 | 已使用同初态的独立前缀程序得到受测时点；不插值、不复用先前终态、不声称单次连续硬件轨迹 |
| 可编程初态和初态制备证据 | CASCAQit 模拟器与状态层 | 已使用公开 `SimulationState.from_amplitudes()` 固化 4 位点基态位串和 state hash |
| AHS 可演示规模 | CASCAQit 模拟器与规划层 | 首版固定为 4 个活动原子、16 维 Hilbert 空间；完整材料晶格不进入本地 AHS 核心 |
| 蛋白实时演化、时间关联函数和动力学观测量 | CASCAQit 算法与结果层 | 蛋白场景只做静态状态网络路径优化；材料 AHS 结果不能外推为蛋白全原子动力学 |
| 周期性电子结构和运行时 DFT | 化学/材料工具链，不属于现有 SDK | 材料能量只作为有来源的离线输入 |

### 16.9 实施顺序与需求编号
