# 投资组合正式应用实现报告

## 本阶段范围

本阶段把投资组合优化从页面原型接入 CASCAQit 的真实本地计算链路。输入、QUBO 构造、QAOA、业务解码、精确基线、标准实验报告和 Bokeh 页面已经连通；其他金融案例不在本阶段实现范围内。

## 已完成

- 定义 8 个合成资产的收益、波动率、协方差、行业和防御属性。
- 将风险收益目标、持仓数量、行业上限和防御资产下限转换为 12 变量 QUBO。
- 通过 CASCAQit `QAOA` 和 `LocalBackend` 执行固定 seed 的本地实验，返回 objective history 和最终 sampling counts。
- 将 QAOA 最佳观测候选与精确枚举基线分开保存，并用原始业务数据重新计算收益、波动率和约束结果。
- 建立包含业务结果、场景分析、模型与求解、量子实验、审计证据五个页签的 Bokeh Server 页面。
- 生成 CASCAQit Algorithm 标准 HTML 报告，并记录 Backend、执行类型、seed、shots、结果哈希、耗时和外部资源访问事实。
- 页面顶部只显示“演示环境”和“合成数据”；运行边界由结果证据生成并集中显示在审计页。

## 当前限制

- 正式应用只有投资组合案例，原型中的其余六个案例尚未接入后端。
- 当前 Backend 是 `LocalBackend`，`execution_kind` 为 `local_simulation`；没有真实硬件、云端或网络执行证据。
- 投资组合采用等权选择，不支持连续权重、交易成本和真实市场数据。
- 当前自动化环境没有可用浏览器实例。服务端渲染回归测试已通过，但本轮 1440×900、1280×720 和 390×844 的最终视觉复核需人工完成。
