# 生物医药第十一阶段：长任务与发布验收报告

日期：2026-07-30

状态：`COMPLETED`

## 1. 持久任务

`LocalJobManager` 默认使用一个工作线程和最多四个排队任务。服务端生成 32 位十六进制 `jobId`，任务状态写入用户数据目录的 `jobs/<job_id>/job.json`。每次状态变化先写同目录临时文件、刷新并执行 `fsync`，再用 `os.replace` 原子替换。

已实现的状态和边界：

- `queued`、`running`、`succeeded`、`partially_succeeded`、`failed`、`cancelled`；
- 每个扫描点、配置和 seed 独立记录状态、报告 hash 或错误；单个运行失败不删除已完成证据；
- 排队任务可取消，运行中任务因 CASCAQit 优化器没有协作检查点而拒绝取消；
- 服务重启后保留终态任务；未到终态的任务标记为 `SERVICE_RESTART_INTERRUPTED`，未完成运行单元标记为 `not_started`；
- 队列满时在创建任何任务目录前返回 HTTP 429。

任务创建接口重新计算分析和计划并核对 `planId`。过期计划返回 `EXPERIMENT_PLAN_STALE`，客户端不能提交自定义运行单元或文件路径。

## 2. 高级页面

生物医药控制区增加标准/高级实验切换。高级模式显示计划运行数、执行策略和估算耗时；提交后轮询任务状态，并按扫描点、配置、seed 展示运行矩阵。矩阵只显示独立运行证据，不自动挑选某次结果覆盖标准单次结果视图。

任务状态按 `jobId` 保存。切换金融领域或其他场景不会删除任务；只有回到任务所属的生物医药场景时才显示对应矩阵。取消按钮只在后端返回 `queued + canCancelPending` 时出现。

## 4. 固定 seed 校准

校准覆盖四个场景、16 个预设、每个预设 3 个固定 seed，共 48 次运行，结果为 `48/48 passed`。高级预设包括：

- LiH 五点势能扫描；
- 1HSG/Indinavir 三构象离散匹配；
- 三中心受挫有效自旋网络；
- 八残基二维离散能景。

高级对接使用 seed `0/3/5`、256 shots 和 24 次目标评估，三次均观测到可行量子候选。高级小肽使用 seed `0/3/6`、128 shots 和 12 次目标评估，三次均观测到最低或次低能候选。三中心 VQE 的绝对误差为 `0.0705～0.1519 meV`，按高级模型 `<0.2 meV` 的发布阈值验收；精确第一能隙仍只标记为经典参考。

完整记录位于 `docs/process/evidence/biomedicine_release_calibration.json`。
