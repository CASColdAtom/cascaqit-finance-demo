# Demo 原型

直接在浏览器打开 `index.html`。页面使用合成数据演示操作流程，不会调用 CASCAQit、真实硬件、云服务或实时行情。

原型包含投资组合、交易结算、调查编排、抵押品分配、流动性调度、授信额度和衍生品定价 7 个案例，共 23 个可切换预设。用户可以调整目标权重、容量约束和业务记录，再查看业务结果、场景分析、模型与求解、量子实验、审计证据五个页签。

前六个案例展示 QUBO、罚项、收敛、采样 counts 和策略对照，结果为固定合成数据。交易结算另有 2×3 原子阵列、Rabi/Detuning/Phase 合并波形和 Hybrid 末端测量。

衍生品案例覆盖欧式看涨、欧式看跌、亚式期权和障碍期权。浏览器会根据当前输入执行 Black-Scholes、二叉树或固定 seed 的 Monte Carlo 参考计算，并展示 Greeks、到期收益、波动率曲面和敏感性。量子页只演示分布编码与 sampling counts；当前没有完整 QAE，counts 不参与价格计算。

运行验收：

```bash
python3 verify_prototype.py
```
